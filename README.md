# EndlessEscalator

Lets you ride the airport escalator indefinitely, without you needing to press any movement keys. The mod uses basic movement state sync to move your character, which lets users use this mod without flagging anticheats.<br>
*Made for Yeet's Bday :)*

With the `2.0.0` update, the mod is now compatible with [SpeedyEscalators by AtomicStudio](https://thunderstore.io/c/peak/p/AtomicStudio/Speedy_Escalators/). Speeeeeedy >:)
